# Каталог образов

Отдельная расширка для SillyTavern: только «Каталог образов», без генератора картинок.
Читает сайты-гардеробы в формате `wardrobe.json` (`chars` / `cats` / `items`).

- несколько каталогов, переключатель в шапке окна (по умолчанию: «Мой гардероб» и «Каталог Ниэль»);
- список каталогов редактируется в Расширения → «Каталог образов»;
- открыть можно там же или из меню волшебной палочки;
- «+» на карточке: скачивает картинку и копирует описание (дальше загружаешь в свой гардероб);
- крупный просмотр по нажатию на картинку.

## Внешности → Context Builder (ExtBlocks)

- окно «Внешности персонажей»: открывается из меню волшебной палочки, из шапки каталога (иконка с лицом) и из настроек;
- берёт раздел «Внешности» с сайта (`wardrobe.json` → `looks`); ссылка задаётся отдельно в Расширения → «Каталог образов»;
- блок выбирается списком в шапке окна: подходит **любой** блок ExtBlocks с Context Builder (generated и rewrite); accumulation и script его не имеют, их в списке нет;
- кнопка «В Context Builder» кладёт текстовый пункт с именем персонажа в названии (без префикса, чтобы имя было видно на телефоне) (роль system) в самый низ списка, под всеми пунктами; повторное нажатие обновляет пункт, а не дублирует;
- текст пункта собирается по шаблону (раскрывашка «Шаблон записи», сохраняется): по умолчанию
  `Как рисовать {{name}}:` → все теги внешности → `ДУБЛИРУЙ ПОЛНОСТЬЮ ВСЕ ТЕГИ ВНЕШНОСТИ ЦЕЛИКОМ.`; `{{name}}` — имя, `{{desc}}` — теги;
- «Своя запись» — ввести имя и теги вручную, без сайта, и отправить по тому же шаблону;
- у добавленной внешности есть «выключить» (глаз) и «убрать» (корзина).

Закрой редактор блока в ExtBlocks перед отправкой — иначе он может перезаписать изменения старой копией.

Ничего не пишет в настройки других гардеробов и не конфликтует с Novarakk (свои классы `wcat-*`, свой ключ настроек).
